# PCB Bucket universel — Dronolab

Conception électronique et routage KiCad du PCB Bucket universel de Dronolab.

## Projet principal

Ouvrir `Bucket_universel_v2.kicad_pro` dans KiCad.

Le dépôt contient le schéma principal, les feuilles hiérarchiques, le circuit imprimé,
les bibliothèques personnalisées et les fichiers de fabrication associés.
